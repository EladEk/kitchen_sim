# Home Studio R145

לאחר הגדרת רהיט ולחיצה על **הוספה לחדר**, מופיעה ההנחיה **הקש על מיקום בחדר להנחת הרהיט**. הרהיט מופיע רק לאחר הקשה או לחיצת עכבר על נקודה תקינה בחדר. ההקשה אינה נשמרת עדיין: נפתח סרגל להזזה בגרירה ובחצים, סיבוב, הצמדה לקיר, שינוי הגדרות ושמירת המיקום. **ביטול הנחה** מסיר את הטיוטה. חזרה להגדרות לפני ההקשה שומרת את המידות והצבע.

הנקודה הראשונה תואמת את ההקשה ללא עיגול לרשת. תנועת מצלמה, גרירת תצוגה, כמה אצבעות וביטול מחווה אינם מניחים רהיט. מיקום חסום או מחוץ לחדר משאיר את ההנחיה לבחירת נקודה אחרת. קובצי העריכה הקיימים והספות הפינתיות נשארים נתמכים.

חבילת Update מיועדת להעתקה לשורש R144 ולאחר מכן בנייה מחדש. FullSource מכיל את המקור המלא, כולל התכנון האישי, ללא קובצי סביבה מקומיים.

אימות: 19 בדיקות קוד ממוקדות ו־7 בדיקות ייצוא עברו. השינויים נשמרו במאגר לפני הבדיקות. במסך בדיקה 394×852 נבדקו ההנחיה ללא רהיט נראה, גרירת תצוגה ללא הנחה, הקשה על נקודה מדויקת, הזזה בס״מ, סיבוב, שינוי מידות, שמירה מפורשת, ביטול וטעינה אחרי רענון. הבדיקה השתמשה בממשק ובבקר ההקשה האמיתיים ובמשטח בדיקה ללא GPU; תצוגת תלת־ממד מלאה ומכשיר אנדרואיד פיזי לא אומתו.
