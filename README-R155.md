# HOME STUDIO R155 — עדכון מתיעוד הדירה

גרסה מלאה המבוססת על R153, כולל הסימולטור האישי והציבורי ותיקון בנייה ללא קובץ hosting.json.

- חדר 1 צמוד לסלון; חדר 2 בין חדר 1 להורים; חדר 3 בין ההורים למחסן. זיהוי החדרים אושר על ידי בעל הדירה.
- חלונות חדרים כהים עם שתי כנפיים ומסילות נפרדות, וכיסויי תריס פנימיים כהים.
- מזגן עילי בחדר הורים ובחדר 3, כחלק קבוע מהמבנה.
- שני אביזרי התקרה משויכים לשירותי האורחים. סוגם המדויק אינו מזוהה ולכן אין הנחה שהם גופי תאורה.
- זוג שקעים בחדר 2, מפסקי כניסה לחדרים ושפופרת אינטרקום בחדר הורים. נקודות לא מזוהות נשארות הכנות.
- לוחות חשמל בצבע לבן במצב אביזרים, צבעי הסימון נשמרים במצב מיפוי.
- התאמת גוני האבן, מסגרות המרפסות וריצוף מבואת השירות לצילומי החוץ.
- תמונות וסרטוני החדרים זמינים במקורות הפרטיים. ציוד זמני, פסולת ואריזות לא הוכנסו למודל.

מידות התוכנית הקיימת נשמרו. מיקומי האביזרים והגבהים מהצילום הם הערכות, לא מדידה בסנטימטרים. הפרטים הקבועים מועברים לתבנית הציבורית של דירות הגן התואמות; אין טענה שכל דירה בבניין צולמה. התכנון והריהוט האישי נשמרים בנפרד מהבסיס הציבורי.

המקורות הפרטיים מוצפנים בבנייה. להפעלה: npm ci; יש להגדיר DOCUMENTS_SECRET לפי README הקיים; npm run build. אין לכלול סודות במאגר. החבילה אינה מעידה על פרסום לאתר החי.

## אימות הגרסה

נשמרו commits לפני הרצת בדיקות. 43 בדיקות עברו: פתחים, תריסים, ממ״ד, חשמל, מעטפת, שכפול פרטים קבועים לדירות הגן והפרדת מידע פרטי מהציבורי. הבנייה המלאה של הלקוח הפרטי, הציבורי והשרת הסתיימה בהצלחה. 297 קובצי מקור מוגנים בבנייה.

בדיקת Chromium חזותית לא הושלמה: סביבת ההרצה חסמה יצירת socket לתהליך הדפדפן. אין טענה לבדיקה חזותית במובייל או לפרסום באתר החי.
