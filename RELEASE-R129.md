# Home Studio R129

WebGL2 is now the default rendering engine in both public and personal district views. Existing browsers adopt it once on their first R129 visit. Subsequent explicit engine selections remain persistent; automatic and forced WebGPU are still available in Options. This does not alter the neutral-lighting preference.

The shared detailed furniture templates now use brown sofa/armchair upholstery, red sofa accent pillows and red bedding on both single and double beds. The original GLB, mesh compression, scanned fabric/normal maps, sheen and furniture dimensions remain intact. Both accent pillows share one added geometry part and the existing red fabric material.

Four garden-apartment terraces are traced independently from the contractor's original building-plan.pdf page 3 paving outlines (drawing indices 46236, 51824, 52275 and 52856). They use the existing surveyed plan registration, including its deskew. The generic outdoor tile finish and height are illustrative; the footprints come from the drawing. Public grass has matching cutouts. All eight district building copies inherit the terraces. In the personal view, apartment 4 retains its own existing terrace and planned garden extension; the standard unit-4 terrace is replaced with that private variant.

Checks and verification limits are recorded in `qa/validation-r129.md`.
