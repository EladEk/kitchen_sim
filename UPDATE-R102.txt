עדכון Home Studio R102 מ־R101

חלצו את תוכן העדכון לתיקיית הפרויקט הקיים, לצד package.json, ואשרו החלפת קבצים.
לא השתנו חבילות התלויות. שמרו את קובצי הסביבה והסיסמה הקיימים.
בצעו commit ו־push למאגר GitHub שלכם כדי לעדכן את אתר Vercel שלכם.
FullSource מכיל את הפרויקט המלא וניתן להשתמש בו גם ללא R101.

הסלונים בדירות הצפוניות בקומות 1–8 תוקנו לפי אזורי הסלון בתוכניות המקוריות.
גם דירות הקרקע הסטנדרטיות משתמשות באזור הישיבה המתוקן, עם מעברים פנויים.
התכנון האישי מציג את הריהוט השמור שלך.

בכניסה לדירה בזמן סיור נפתחת מפת הדירה אוטומטית. המפה מציגה קירות,
פתחים, ריהוט ודלתות פתוחות או סגורות. הנקודה הכחולה מסמנת את המיקום שלך
והחץ מציין את כיוון המבט. המפה עוקבת אחר הדירה והקומה שבהן אתה נמצא בפועל,
בכל שמונת הבניינים, כולל הבניינים המסובבים והמשוקפים.
אפשר לסגור ולפתוח את המפה בכפתור ״מפה״. במעבר לדירה חדשה היא נפתחת שוב.
המפה משתמשת בתרשים שמור ומתעדכנת חמש פעמים בשנייה בלי ליצור מודל נוסף.

בדיקות התוכניות, המעברים, 344 צירופי בניין/דירה, 400 דלתות במפה,
התכנון האישי, השמירה, התנועה, הזיכרון, ההרשאות והבנייה עברו.
התרשימים נבדקו ברינדור מקומי. התצוגה וקצב התמונה בטלפון ובמשקפי VR
עדיין לא אומתו במכשירים אמיתיים.

אם קשה להוריד את הקובץ המלא, הורידו את כל ארבעת החלקים וחברו אותם לפי הסדר
לקובץ ZIP אחד, ואז חלצו אותו. החלקים אינם ארכיונים נפרדים.
ב־Windows Command Prompt, באותה תיקייה שבה החלקים נשמרו:
copy /b HomeStudio-R102.zip.part-01+HomeStudio-R102.zip.part-02+HomeStudio-R102.zip.part-03+HomeStudio-R102.zip.part-04 HomeStudio-R102.zip
ב־macOS או Linux:
cat HomeStudio-R102.zip.part-0[1-4] > HomeStudio-R102.zip
