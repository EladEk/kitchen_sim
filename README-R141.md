# Home Studio R141

## פעולות זמינות בראש חלון הבנייה

כפתורי **הנח רהיט**, **ביטול**, **בטל פעולה** ו־**סיום** נמצאים יחד בראש חלון הבנייה בלייב. רק גוף החלון נגלל, כך שהכפתורים נשארים גלויים גם בנייד בזמן שינוי סוג, מידות וצבע. הנחה זמינה אחרי בחירת מיקום תקין; ביטול פעולה זמין אחרי שינוי שנשמר.

## עריכת כל חדר בנפרד בלייב

פתחו דירה ובחרו **אפשרויות → בנייה בלייב בתלת־ממד → עריכה לפי חדר**. בחרו חדר מרשימת החדרים בתוכנית הדירה. התצוגה מתמקדת בחדר, רשימות הרהיטים והשידות מסתננות אליו ומיקום חדש נבדק בגבולות החדר. חדרים בעלי שם זהה מסומנים במספרים כדי להבדיל ביניהם. **כל הדירה** מחזיר את התצוגה ואת כל הרהיטים.

מעבר חדר מבטל את התצוגה המקדימה שטרם הונחה ושומר את הריהוט שכבר הונח בכל החדרים. סוג הרהיט, מידותיו וצבעו נשארים זמינים לתוספת בחדר הבא. השמירה האוטומטית בדפדפן, השמירות בשם וגיבוי/טעינה מקובץ ממשיכים לעבוד באותו פורמט של R138–R140.

## קבצים והתקנה

המקור המלא נמצא בתיקיית **HomeStudio-R141**. חבילת **Update** מיועדת להעתקה לשורש **R140**, ואחריה בנייה מחדש. קובצי הסביבה המקומיים שלכם נשארים אצלכם.

## אימות

עברו 569 בדיקות מקור ו־20 בדיקות של תוצר הבנייה, כולל שמירה ותאימות לקבצים קודמים, חדרים, דירות, טלוויזיות וחיבוריהן, דלתות, מעליות, מדרגות וחזיתות. בדיקות ההגנה על הנכסים הפרטיים עברו.

רכיב הבנייה האמיתי נבדק בדפדפן בתוך תצוגה ברוחב 394 ובגובה 852 פיקסלים: ארבעת הכפתורים נשארו גלויים באותה שורה בגובה לחיצה של 44 פיקסלים גם לאחר גלילה; הוספת שולחן בחדר ראשון ומיטה בשני, סינון הרשימות, חסימת מיקום מחוץ לחדר, ביטול מיקום, ביטול הפעולה האחרונה ושחזור שני החדרים אחרי רענון עברו.

בדיקת הממשק השתמשה בכפתורי נקודות במקום הצבעה בסצנה, עם מודולי המיקום, בחירת החדר והשמירה האמיתיים. בדיקת GPU מלאה ומדידת ביצועים במכשיר Android לא בוצעו. עמודי הבדיקה אינם נכללים בפרסום האתר.
