# Public limestone texture — R96

`limestone-r96.png` is an illustrative AI-generated ivory limestone albedo,
created with the built-in image generation tool. It is not a manufacturer scan
or a photograph of a particular apartment. The actual image is 1254 × 1254;
the runtime prepares 512-pixel mobile / 1024-pixel desktop GPU maps, with aligned
relief and roughness estimated from luminance. Scale is approximately 1 m.

Generation prompt:

> Generate a production-ready seamless PBR BASE COLOR texture for the cream/off-white limestone cladding of a modern residential apartment building in Israel. Square 2048x2048 image, a flat orthographic macrophotographic material scan filling the entire image edge to edge. Fine natural limestone pores, extremely subtle warm ivory mineral grains and very faint fossil flecks, restrained realistic irregularity, uniform pale pearl/ivory overall appearance. This represents one continuous stone surface 1 metre across; NO blocks, NO mortar lines, NO grooves, NO labels, NO border. Pure diffuse albedo: neutral evenly lit surface with no directional shadows, no highlights, no vignetting, no ambient occlusion and no color gradient. Perfectly seamless tiling at all four image edges. Photographic surface detail, not illustration, no camera scene, no perspective. Intentionally low contrast for physically based lighting; bright ivory but with no clipped whites. Output only the material texture.

Other surface maps, foliage masks and contact masks are deterministic code-native
textures. No owner photographs, catalog samples or personal design changes are
used by these new public assets.
