# Home Studio R144

הוספה, גרירה, העברה לחדר אחר, שמירה ושינוי גובה סרגל אינם מאפסים את המצלמה ואינם משנים את החדר המוצג. רק בחירת דירה או חדר לצפייה משנה את המיקוד.

לחיצה על רהיט פותחת סרגל הזזה ייעודי: הצמדה לקיר, סיבוב 90°, שמור מיקום, הגדרות הרהיט והחזרה למיקום קודם. החיצים וגודל הצעד נשארו זמינים. גרירה וחיצים מציגים טיוטה בלבד; שמור מיקום מאשר את השינוי, והחזרה למיקום קודם מבטלת אותו. בשני המקרים חוזרים לקטגוריות הריהוט. בהגדרות אפשר לשנות גם את חדר היעד בלי לשנות את המבט.

הקטלוג מכיל 38 סוגים. נוספו ספה פינתית, שזלונג, ספה דו־מושבית, הדום, כיסא משרדי, ספת אירוח, קונסולה, מזנון אחסון, אי למטבח וספסל אחסון.

בספה פינתית מגדירים בנפרד את אורך הזרוע הראשית ואת אורך הזרוע הצדדית, כולל הפינה. אפשר לקבוע את עומק המושב ואת צד הפינה. המידות נשמרות בקובצי העריכה, ותצוגת הפריט מבוססת על אותו מודל שמופיע בחדר. הפינה הפנימית הפנויה מאפשרת מיקום פריטים והליכה.

חבילת Update מועתקת לשורש R143 ולאחריה נדרשת בנייה מחדש. FullSource מכיל את המקור המלא, כולל התכנון האישי, ללא סיסמאות וקובצי סביבה מקומיים.

אימות: 28 בדיקות קוד ממוקדות ו־11 בדיקות על הייצוא הבנוי עברו. נבדקו התאימות לשמירות קיימות, הקטלוג, ההצמדה לקיר, טלוויזיות על שידות, התצוגה לפי חדר ומידות הספה הפינתית. בדפדפן 394×852 נבדקו גרירה אמיתית ללא שמירה אוטומטית, אישור שמירה, ביטול, העברה לחדר אחר בלי שינוי החדר המוצג, וחזרת ספה 320×230 ס״מ עם מושב 85 ס״מ ופינה שמאלית אחרי רענון. נעשה שימוש בממשק האמיתי ובמשטח בדיקה ללא GPU; סצנת תלת־ממד מלאה וביצועי אנדרואיד פיזי לא אומתו.
