# Home Studio R139

## דירות ללא ריהוט אוטומטי

דירות הבסיס נפתחות עם המבנה, הפתחים והכלים הסניטריים. הוסרו הרהיטים, המטבחים והמכשירים האוטומטיים מכל 43 הדירות במתחם, כולל דירות הגן. ההסרה חלה על תצוגת התלת־ממד, המפה וההתנגשויות בסיור. ריהוט השטחים המשותפים נשמר.

רהיטים שכבר הוספתם בעורך נשמרים. התכנון האישי הקיים של בעל הדירה נשמר כעיצוב שבעל הדירה הכין. הסרת הריהוט האוטומטי אינה מוחקת שמירות משתמש.

## עריכה לפי חדר

פתחו **אפשרויות → פתיחת עורך הדירות**, בחרו בניין, קומה ודירה, ואז **עריכה לפי חדר**. אפשר לבחור חדר הורים, חדר ילדים, ממ״ד, חדר עבודה, סלון, פינת אוכל, מטבח או חדר שירות ורחצה לפי תוכנית הדירה.

בחירת חדר ממקדת את התוכנית ואת רשימת הפריטים וממקמת בו תוספות חדשות. פריטים בחדרים אחרים נשמרים. לחצו על **הצגת החדר בתלת־ממד** כדי לקבל חתך ממוקד של החדר. בחירת **כל הדירה** מחזירה עריכה ותצוגה של הדירה כולה.

הגדלים והזזות ניתנים בס״מ; הסיבוב במעלות. נוסף **גובה מהרצפה** לטלוויזיות תלויות, לארונות עליונים ולפריטים אחרים. גובה כולל מרבי נתמך: 280 ס״מ.
