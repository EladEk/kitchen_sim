# Home Studio R143

העריכה מתבצעת בתלת־ממד בלבד. עורך התוכנית המקביל הוסר; **אפשרויות → שמירה וטעינה** מאפשר לשמור בשם, לשחזר ולייבא או לייצא קובץ. לחיצה על רהיט גם מחוץ למצב הבנייה פותחת מיד את עריכתו בתלת־ממד.

לחיצה על רהיט קיים בוחרת אותו להזזה. גררו את הרהיט עצמו ושחררו כדי לשמור, או השתמשו בארבעת החצים. החצים מכוונים לפי המבט הנוכחי גם בבניינים מסובבים ומשוקפים. ניתן לבחור צעד של 1, 5, 10 או 25 ס״מ. גם חצי המקלדת פועלים; Shift עם חץ מזיז בס״מ אחד. גרירה מחוץ לרהיט מסובבת את המצלמה. **הגדרות** פותח את מידות הרהיט והצבע.

הזזות תקינות נשמרות לאחר שחרור או לחיצה על חץ. ניתן לבטל פעולה או לבטל מיקום לא תקין. חפיפות וחציית קירות ממשיכות להיבדק. הזזת שידה מעדכנת גם טלוויזיה שמחוברת אליה.

**גובה קירות בעריכה** מציע קירות מלאים, חתך 110 ס״מ, חתך 35 ס״מ או תצוגה ללא קירות. החיתוך משנה את התצוגה בלבד: הקירות, הדלתות וההתנגשויות במבנה המקורי נשמרים. הרהיטים שהדייר הוסיף מוצגים בגובהם המלא. יציאה ממצב הבנייה מחזירה תצוגה מלאה.

כפתור **צמצום פס העריכה** מקפל את הקטלוג וההגדרות ומגדיל את שטח החדר. כפתורי התזוזה, שמירת המיקום, הביטול והסיום נשארים זמינים לרהיט הנבחר. **הרחבת פס העריכה** פותח אותו שוב בלי לאבד את הבחירה או את המידות.

המקור המלא נמצא בתיקיית HomeStudio-R143. חבילת Update מיועדת להעתקה לשורש R142, ולאחריה בנייה מחדש. קובצי הסביבה המקומיים שלכם נשארים אצלכם.

אימות: 577 בדיקות קוד ו־22 בדיקות על הייצוא הבנוי עברו עבור ההזזה וחתך הקירות. בדפדפן בגודל 394×852 נבדקו גרירה אמיתית, חיצים, צעד של ס״מ, ביטול פעולה, שמירה אחרי רענון וצמצום הפס: שטח התצוגה גדל מ־519 ל־715 פיקסלים. בדיקת הדפדפן השתמשה בממשק האמיתי ובמשטח בדיקה במקום סצנת GPU מלאה; ביצועי אנדרואיד פיזי לא נבדקו. לאחר הסרת עורך התוכנית בוצעה בנייה סופית בלבד בלי להריץ מחדש את הבדיקות שלא השתנו.
