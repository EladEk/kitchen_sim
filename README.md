פרויקט נקי להרצה, עם כל תיקוני הגרסה העדכנית. מנועי WebGPU/WebGL2,
הטקסטורות והמודלים נשמרו ללא דחיסה נוספת או שינוי באיכות. נכללים גם
מפענחי KTX2/Basis, דגימות חומרי הרצפה והפרדה בין הגישה הציבורית והאישית.
הוסרו תמונות וסרטוני תיעוד, קובצי PDF, צילומי QA, תוצאות בדיקות ישנות
וכלי הפקת נכסים שאינם דרושים להרצה. ספריית הדירות והעריכה נשמרו.

## הרצה

Node.js 22.12 ומעלה; מומלצת Node.js 24.

```sh
npm ci
cp .env.example .env.local
```

הגדירו בקובץ המקומי DOCUMENTS_PASSWORD ו-DOCUMENTS_SECRET (מפתח בסיס־64
של 32 בתים או סוד ארוך). אין בחבילה סיסמאות או מפתחות של האתר החי.
אפשר ליצור מפתח מקומי באמצעות:

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
npm run dev
```

פתחו http://localhost:4173. הפקודה בונה גם את האתר הציבורי ואת הגישה האישית.
לאחר שינוי בקוד מפעילים מחדש את הפקודה. לבנייה בלבד: npm run build.
להרצת התוצר שנבנה: npm start. בדיקות הליבה הכלולות: npm test.
לכל בדיקות המקור, חומרי התיעוד וכלי הפיתוח השתמשו ב-FullSource.
